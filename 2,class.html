HTML, which stands for HyperText Markup Language, is the standard code used to structure and arrange content on a web page. It is not a programming language; rather, it is a markup language that tells a web browser how to display text, images, links, and multimedia.

Invented by Tim Berners-Lee in 1991, HTML works alongside CSS (which styles the visual layout) and JavaScript (which adds interactive elements) to power the modern World Wide Web.
